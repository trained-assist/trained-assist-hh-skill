# Мобильный аудит ЛК (360/390) — issue #174

Дата: 2026-10-05. База: `4987457` (origin/main). Метод: реальный рендер всех 8 экранов навигации в Chromium на ширинах 360×800 и 390×844, герметичный харнесс (реальная таблица маршрутов `handleHhPublic`, моки HH + LLM, без реальных отправок). Исполняемый тест: `tests/audit/mobile-layout.spec.cjs` (3 проверки), сырые замеры: `audit/mobile-inventory.json`.

## Что было сломано (до фикса, 360px)

| Экран | Горизонтальный вылет страницы | Причина |
|---|---|---|
| `/hh/review` | **116px** | 6 вкладок-фильтров в один ряд (`.tabs` без переноса) — вся навигация по откликам уезжала за экран |
| `/hh/sync-log` | **256px** | 6-колоночная таблица журнала без скролл-обёртки — страница целиком уезжала вбок |
| все 8 экранов | — | пункты меню ЛК были ~24px по высоте (ниже пальца) |

## Что сделано

1. **`/hh/review` — вкладки-фильтры переносятся** (`src/hh-review-page-html.js`, медиа-запрос ≤640px): `.tabs{flex-wrap:wrap}`, `.tab-btn{min-height:40px}`. Вылет 116px → 0.
2. **`/hh/sync-log` — таблицы в скролл-обёртке** (`src/hh-routes.js`): `.table-scroll{overflow-x:auto}` + `min-width` у таблиц. Вылет 256px → 0; таблица скроллится внутри себя, страница — нет.
3. **Навигация ЛК — высота пунктов 40px на мобильном** (`src/hh-nav.js`, общий стиль для всех 8 экранов): `min-height:40px;display:inline-flex;align-items:center`. Один фикс вместо восьми правок страниц.
4. **Массовые действия на `/hh/review` — 44px по высоте** (`.btn-send-all/.btn-reject-all{min-height:44px}`, `#regenAllBtn` на всю ширину): «Отправить (N)», «Отказать (N)», «Перегенерировать все» доступны пальцем и не режутся по краю.

## Проверка (после фикса, 360 и 390)

- Горизонтальный вылет: **0px на всех 8 экранах** на обеих ширинах (было 116 и 256).
- Массовые кнопки `/hh/review` при 360: все три в пределах экрана, высота 44px.
- Пункты меню ЛК: ≥40px на всех экранах.
- Desktop не сломан: 1047 юнит-тестов зелёные, `nav-hierarchy.spec.cjs` (3/3) зелёный.

## Осталось на потом (честно, не починено)

Мелкие интерактивные цели (<32px) на второстепенных элементах: поля ввода и чекбоксы в ATS-редакторе (33 шт.), пресеты/фильтры холодного поиска (19), карточка кандидата (7). Это не блокирует работу с кандидатами с телефона, но пальцем неудобно. Зафиксировано в `audit/mobile-inventory.json` (поле `small`).
